# [02/12] 실제 원고 정보 추출 예비 대조 — 2026-11-05

> **판정: 모델 예비 대조 및 검수 준비 완료 / 독립 인간 정답표 미완료.** 실사용 품질 평가의 통과 판정이나 정밀도·재현율 수치가 아니다.

## 목적과 범위

Task 02의 목표는 실제 소설에서 ChatGPT가 어떤 설정을 놓치거나 잘못 추출하는지 독립적으로 검증할 **금표준 정답표**를 확보하는 것이다. 현재 제공된 한 작품의 1~5화를 분석 대상으로 유지한다. 원고 내용·대사·근거 인용·후보 JSON·검토표·SQLite는 GitHub 공개 저장소에 올리지 않는다.

## 이번에 검증한 산출물

| 항목 | 결과 |
| --- | ---: |
| 실측 출처 파일 | 1~5화, 5개 |
| 이전 모델 후보 | 26개 |
| 이번 모델 예비 검토가 추가로 제안한 항목 | 45개 |
| 검토 작업표의 전체 후보 | 71개 |
| 문자 범위와 원문 해시를 기계 검증한 예비 추가 항목 | 45/45 |
| 독립 인간 검토 완료 | 0개 |
| 공식 DB에 추가 등록·승인·적용한 사건 | 0개 |
| 정밀도·재현율·F1 | **미측정(null)** |

새로 추가된 45건은 확정된 누락 정답의 수가 아니다. 모델이 기존 후보 26건을 기준으로 재검토하면서 선정한 **잠재적 누락 및 보강 항목**이다. 71개가 원고 전체 사실의 총수라는 주장도 성립하지 않는다.

### 예비 점검에서 드러난 우선 유형

- 주요 인물과 각각의 관계·역할이 구조화되지 않은 경우
- 계약 초안의 조건부 보수를 실제 지급 사실과 구분해야 하는 경우
- 같은 과거 금액이 여러 장면에 재등장하는 경우
- 조사 과정에서 확인된 정상 거래와 미확정 자금 흐름을 구분해야 하는 경우
- 가문 소유권·회사 자산 명의·지원 혜택·실제 현금의 범위를 구분해야 하는 경우
- 명령이나 계획을 실제 실행된 사건으로 오인할 위험
- 소급 사건·상대적 날짜 및 과거 회상을 명시적으로 추적할 필요

이 유형을 근거로 추출 프롬프트를 즉시 대규모 변경하면 **모델이 자체 생성한 평가 항목에 과적합**될 수 있으므로, 인간 독립 검수 전에 의미 추출 성능 향상을 주장하지 않는다.

## 공개하지 않은 비공개 작업물

다음 항목은 Moon의 `/shared/NovelGraph-data/works/ashcroft-pilot-20261104/reports/`에만 저장돼 있다.

- `fact-gap-proposals-20261105.json`: 예비 추가 45건과 해석상 주의사항, 원문 범위·SHA
- `fact-review-worksheet-v2-20261105.json`: 26+45 후보, 검수 상태 모두 미검토
- `fact-review-worksheet-v2-20261105.md`: 독립 검수자가 읽을 수 있는 1~5화 작업표
- `prepare_gap_audit_20261105.py`: 예비 대조에 사용한 private 스크립트

작업표는 **두 번 읽는 절차**로 정리했다.

1. **블라인드 1차:** 검수자가 원고 전체를 읽고 중요 사실 및 누락 후보를 스스로 기록한다. 모델 후보 목록은 이 단계에서 먼저 보지 않는다.
2. **대조 2차:** 기록한 목록을 기존 26건 및 새 예비 후보 45건과 비교해 정확·부분정확·중복·근거부족·오류를 분류한다. 사용자 승인도 별도로 기록한다.

이렇게 해야 모델이 놓친 내용을 검수자도 함께 놓치는 평가 편향을 줄일 수 있다.

## 안전 및 검증 결과

- 모든 추가 항목은 지정된 회차 원본의 Unicode 문자 범위와 인용문 일치를 검사했고, SHA-256이 원고 판본과 일치했다.
- 실제 DB의 기존 26건은 모두 `proposed`; 적용 사건 0건.
- 원래 검수 작업표와 원본 1~5화는 변경하지 않고 **v2를 별도 파일로 생성**했다.
- 신규 private 파일은 권한 0600, 사용자 원고가 있는 디렉터리는 0700.
- 이 단계에서 프로덕션 Python 코드와 공개 테스트 픽스처는 변경할 필요가 없다고 판단했다. Ponytail 원칙에 따라 문서·실측 기록만 공개 저장소에 반영한다.
