# [02/12] 실제 1~5화 후보 71건 의미 검토 — 2026-11-05

> **판정: ChatGPT 모델 단독 예비 검토 71/71 실시 / 독립 인간 정답표 미완료.** 아래 분류는 모델의 판단이며, 검수 완료 수·오류 확정 수·정밀도/재현율이 아니다.

## 범위

- 실제 비공개 원고: 동일 작품 1~5화
- 기존 공식 `proposed` 후보: 26건
- 앞선 모델 예비 보강 후보: 45건
- 의미 및 근거 검토 항목: **총 71건**
- 각각의 `review_id`, 회차, 원문 Unicode 문자 구간, 원고 SHA-256을 다시 비교했다.
- 실사용 DB의 승인 상태·월드 스테이트를 일절 변경하지 않았다.

## 모델 예비 분류

| 모델의 예비 의견 | 건수 | 해석 |
| --- | ---: | --- |
| `direct` | 50 | 해당 인용이 제한적으로 정의된 주장을 직접 뒷받침한다고 모델이 판단 |
| `context` | 8 | 해당 문장 외에 앞뒤 서술까지 연결해야 주장을 설명할 수 있음 |
| `repeated` | 4 | 앞에서 기록된 사실·거절·지급 합계를 다시 언급함. 동일 사건을 중복 실행·중복 차감하지 않도록 주의 |
| `semantics` | 3 | 공식 후보의 사건 유형 또는 현행 상태 필드가 원문의 확정·미확정 구분과 어긋날 가능성 |
| `span` | 5 | 인용문 한 구간이 주장 전체를 충분히 증명하지 못해 근거 보강 필요 |
| `uncertain` | 1 | 실제 법적 서명·효력 등 원문에서 미확정 |
| **합계** | **71** | **전부 독립 검수 미완료** |

`direct` 50건을 '정답 50건'이라고 읽어서는 안 된다. 모델의 동일 세션 판단이며 블라인드 독립 검수에 의한 판정이 아니다.

## 다음 검수에서 우선 확인할 사례

1. **다우존스 매각:** 1화 시점 최종 매각계약 미체결과 뒤이어 이루어진 아이작의 매각 거절은 다른 상태다. `pending` 하나로 회차 종료 상태를 표현하면 의미가 틀릴 수 있다.
2. **관리위원회 위임:** 3화의 인용에서는 서명하지 않고 제안을 거절했다고 한다. `current_status=pending`이 실제 계약 상태를 왜곡할 수 있다.
3. **자산 유출 입증:** 3화의 '부당 유출이 아직 입증되지 않았다'는 증거 수준을 말하며 별도 불법 사건·현금 이체의 발생을 뜻하지 않는다.
4. **과거 자문료 320만 달러:** 3·4·5화의 동일 지급 합계에 대한 반복 언급이며 960만 달러의 새로운 지출로 더하면 안 된다. 아이작 개인 보유 현금의 유출로 처리해서도 안 된다.
5. **4화의 일부 자금 이동:** 현 후보에 붙은 부정형 인용만으로 부분 이동을 완전히 입증할 수 없으며, 앞선 긍정형 송금 설명 근거가 별도로 필요하다.
6. **4화 인물 관계:** 에드워드·필립·로런스의 이름이 등장하는 문장만으로 각각의 관리위원회·성공보수·위임 검토 역할이 입증되지는 않는다. 역할을 지칭하는 별도 문장의 위치를 연결해야 한다.
7. **5화 지원 중단:** 결정·다음 지급 중단 방침은 실제 지급 취소·회수 또는 신탁 분배금 중단과 구분한다.
8. **5화 과거 비밀유지 약정:** 기존 협상 문서 확인 지시만으로 현재 유효한 비밀유지 계약의 상세 서명 상태·효력까지 확정하지 않는다.

위 항목은 **결론이 아닌 검수 질문**이다. 실제 원고가 논리적으로 모순된다는 판정은 독립 검수를 거쳐야 한다.
