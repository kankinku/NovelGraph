# 복구 및 후속 개발 계획

## 1. 원본 복구

- 과거 Moon 인스턴스의 `작가/_tools/novelgraph` 위치 확인
- 커밋 `909e00d` 및 주변 Git 이력 확인
- 원본 데이터·설정·테스트 결과를 사본으로 백업
- 사용 중인 저장소와 브랜치, 미커밋 변경 확인

## 2. 전수조사

- CLI 명령 및 인터페이스 인벤토리
- MCP 호출 경로 확인
- 후보 관리, 승인, 상태 전이, 그래프 어댑터 및 테스트 검토
- 구현/부분구현/미구현/회귀 기능을 구분

## 3. 핵심 개발

- Graphify 실질 연동 검증 및 부족 기능 구현
- 투자·계약·자산·관계 상태 전이와 시점 복원
- 출처 추적, 불확실성, 승인 워크플로 보완
- 시간·행동·수치 충돌 감지

## 4. 실전 검증

- 소설 1~3화로 상태 전이 및 추출 정확도 재검증
- 범위 확장 후 1~43화 연속성 검증
- 오탐/누락/근거 링크 품질 평가
- Moon MCP만으로 종단간 실행 검증

## 완료 조건

- 실제 원본 코드 및 히스토리 확보
- 재현 가능한 테스트 명령·결과 보유
- 상태 변화가 원문 근거 및 시점과 정확히 연결
- 분류·오류 검증의 실증 지표 확보
