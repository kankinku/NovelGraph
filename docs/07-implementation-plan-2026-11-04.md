## 0. 목표와 비목표

**목적:** 장편 웹소설을 ChatGPT가 의미 해석해 인물·사건·날짜·장소·계약·자산·관계·복선을 구조화하고, 원문 근거와 함께 회차별 세계 상태를 복원하며 설정 충돌을 검출한다.

**필수 사용자 흐름:** `Moon MCP로 원고 읽기 → ChatGPT가 JSON 후보 추출 → Moon으로 후보 전달 → 검증·격리 → 승인 근거 확인 → 사건 적용 → 상태 질의·충돌 검증 → 출처 회차/문장 포함 보고`.

**범위 밖:** 자동 집필, 다음 화 생성, 자동 퇴고, 무인으로 유료 LLM API 호출, 웹 UI/서버/별도 MCP 개발(기존 Moon으로 충분한 동안), 초기 단계 분산 DB·벡터 DB·Neo4j·복잡한 플러그인 체계.

**실행 제약:** ChatGPT 모델의 의미 추출은 대화에서 호출할 때만 가능하다. Moon 자체가 같은 모델을 무인으로 호출한다고 가정하지 않는다. 외부 LLM API를 허용하지 않는 이상 무인 일괄 의미 추출을 '완료'로 표현하면 안 된다.

## 2. 아키텍처 결정

```text
ChatGPT: 원고 의미 이해 / 사건·근거 후보 추출 / 모호성 판정
  ⇅ 기존 Moon MCP (원고 읽기, JSON 전달, 결과 읽기)
NovelGraph CLI (Python): 입력 검증, 출처 일치, 저장, 상태 재생, 충돌 검출
  ├─ SQLite: Episode / Evidence / Candidate / Entity / Event / StateChange / Finding
  └─ Graphify 어댑터: 노드·관계 출력 및 탐색(호환성 실증 후 연결)
```

- 단일 머신·단일 사용자 배치 작업을 **초기 가정**한다. 다중 쓰기·웹 운영은 실제 요구가 생기기 전까지 제외한다.
- **SQLite의 검증된 사건·상태 이력이 기준 진실(source of truth)**이다. Graphify는 탐색 그래프 역할로 연동한다. 그래프 파일만으로 현금 잔액이나 시간 순서를 판단하지 않는다.
- Graphify의 공개 기본 기능은 범용 코드/문서 지식 그래프다. 소설의 '계약 체결≠지급≠지분 양도'를 자동으로 처리한다고 가정하지 않는다. 먼저 호환성을 짧게 검증한다.
- 초기 구현은 Python `argparse`, `json`, `sqlite3`, `decimal`, `unittest` 등 표준 라이브러리를 최대한 사용한다. Graphify가 필요할 때만 공식 `graphifyy`를 격리 환경에 설치한다.
- 별도 MCP 서버는 **Moon의 CLI 실행/파일 입출력이 실제로 요구를 충족하지 못한다는 증거가 나올 때만** 검토한다.

## 3. 최소 데이터 계약(초안 — 소스 복구 시 우선 비교)

| 개념 | 필수 필드 |
| --- | --- |
| Episode | 작품 ID, 화 번호, 파일/콘텐츠 해시, 원고 버전 |
| Evidence | 작품 ID, 화 번호, 원본 해시, 위치(문단/행/범위), 정확한 원문 |
| Entity | 작품 내부 안정 ID, 유형, 이름·별칭, 동일인 확인 상태 |
| Candidate | 종류, 구조화된 주장, 근거 ID, `proposed/approved/rejected`, 검토 사유 |
| Event | 사건 ID, 참여자, 종류, 이야기 내 발생 시점, 서술 순서, 근거 ID |
| StateChange | 대상 엔티티, 속성, 연산·전후 상태 또는 증감, 단위/통화, 사건 ID |
| Finding | 판정, 비교하는 근거 ID들, 이유, 검토 필요 여부 |

**유의:** 시간은 (1) 원고에 쓰인 실제 발생일, (2) 회차/서술상 순서, (3) 나중에 알려진 사실의 발견 시점으로 구분한다. 미상 값은 추정으로 채우지 않는다. 수치는 `Decimal`로 계산하고 통화·평가 기준을 보존한다. 총자산은 현금과 동의어가 아니며 정보가 부족할 경우 추정 계산을 하지 않는다.

## 6. 데이터 보안 및 Git 작업 규칙

- 현재 GitHub 저장소는 **public**이다. 미공개 원고, 개인 메모, 실제 자산·계약 자료, API 자격 증명, 분석 산출물은 절대 커밋하지 않는다.
- 개인 데이터와 로컬 DB는 공개 저장소 밖의 `/shared/NovelGraph-data/` 등 별도 경로에 보관한다. 실제 저장 경로/접근 권한은 구현 단계에서 확인한다.
- 복구 시 삭제/덮어쓰기/강제 reset 금지. 과거 원본은 복사하여 보존하고 손상 위험 작업 전에 독립 백업한다.
- 외부 플러그인 설치나 Graphify 설치는 프로젝트 격리 환경에 한정하고 버전·라이선스·실행 결과를 기록한다.
- 변경마다 `관련 테스트 → 변경 검토 → Git diff → 기록/커밋` 순서로 확인한다. 테스트 실패나 누락은 성공으로 기록하지 않는다.

## 7. Ponytail / Karpathy 평가

**채택:** 원본 우선, 작은 기능 단위, 필요 조건을 만족하는 첫 번째 간단한 해법, 입력 검증·금전 계산 테스트, 기존 Moon MCP 재사용, 불확실성 명시, 단계별 구체적 통과 조건.

**보류:** 신규 독립 MCP, 웹 대시보드, Neo4j/벡터 DB, Graphify 대규모 포크, 장기 실행 자동 에이전트, 범용 도메인 프레임워크, 자동 집필. 요청/실증으로 필요해질 때만 재검토한다.
