# NovelGraph 연재 안전 게이트 — 2026-11-09

## 목적
Grill-me 확정 정책에 따라 집필 AI가 **검증된 현재 상태**를 참고하도록 지원하고, 드러난 확정 충돌은 원고 확정 전 반려한다. 이 기능은 원고 집필이 아니라 **검증 가능한 현재 상태 관리 도구**다.

## 1. 중복 자산 합산 방지
- 같은 통화의 `cash`와 미분류 `liquid` 항목은 같은 돈을 가리킬 수 있다. 이 경우 `query-state --scope assets`와 `net_assets`의 `totals.ambiguous_cash_liquid_currencies`에 통화를 표시하고, 그 통화의 숫자 합계는 **반환하지 않는다**. 개별 원본 항목은 조회 가능하다.
- 현금과 **별개라는 원문 근거가 확인된** 유동자산만 LLM 후보 `state_set`의 `category=liquid`에 `separate_from_cash: true`를 넣을 수 있다. 기존 승인·원문 검증 절차를 반드시 통과해야 한다.
- 표기된 합계는 '확인된 값만'의 합계이며, 원고에 언급되지 않은 보유분까지 없다고 단정하지 않는다.
- 동일 자산의 여러 평가 지표를 서로 다른 항목에 중복 등록하는 문제는 이 방어만으로 전부 해결할 수 없다. 자산별 고유 ID와 평가 기준을 후속 검증 대상으로 유지한다.

## 2. 초고 충돌 검사 (읽기 전용)
확정 원고를 반영하기 **전**, LLM이 원고에서 추출한 근거 후보 JSON과 직전 공식 회차를 비교한다.

~~~bash
/shared/NovelGraph/.venv/bin/python -m novelgraph \
  --data-root /shared/NovelGraph-data \
  draft-gate --source /shared/NovelGraph-data/draft-002.txt \
  --input /shared/NovelGraph-data/draft-002.candidates.json \
  --as-of-episode 1
~~~

- `REJECTED`: 알려진 현금을 넘는 지출, 현재 시간 역행, 중복 체결, 서명 없는 지분 이전, 미체결 계약 연동 금전 거래 등 **확정 가능한 구조적 모순**. 원고 확정 중단 후 요청한 AI가 원문/DB를 먼저 검토하며, 최종 판단은 사용자에게 있다.
- `NEEDS_REVIEW`: 위 자동검사에서 확정 충돌을 찾지 못한 경우. **정상 확정 또는 공식 승인과 같지 않다.** 의미·고증·관계가 맞는지는 AI/사용자 검토가 더 필요하다.
- 모든 반환값 `blocking=true`, `official_world_state_mutations=0`. 초고는 공식 원장에 저장하지 않으며 원문 내용은 CLI 결과에 포함하지 않는다.
- 지금 제공되는 것은 **충돌 판정 결과를 반환하는 명령**이다. Teller 또는 외부 집필 에이전트가 `blocking`을 강제하도록 연결하는 작업은 별도다.

## 3. 미완료 및 출시 기준
- **자동 반영 미구현**: LLM이 확신한다고 주장했다는 이유만으로 공식 승인 원장을 갱신할 수 없다. 기계적으로 확인 가능한 사건인지 검증하고, 판단이 필요한 건 자동으로 보류하는 안전한 정책이 필요하다.
- **외부 집필 단계 연동 미구현**: 초고 검증/반려를 집필 파이프라인의 필수 관문으로 연결해야 한다.
- **실제 원고 평가 미완료**: 독립 검수 결과를 정답으로 하는 정확도, 누락률, 상태 재현성을 측정해야 한다.
- **역사 고증 검증 미완료**: 외부 역사 자료에 근거한 검토는 별도 프로세스다.
- 기존 승인 원장·사건 이력·Graphify 원본 코드를 변경하지 않는다.
