# 연속성 검증

| 유형 | 예시 | 검증 조건 |
| --- | --- | --- |
| 시간 | 같은 만남이 월요일/화요일로 기록 | 날짜·기준 시간·회상 여부 확인 |
| 행동 | 종료된 행동 반복 | 장면 전환·재실행 근거 확인 |
| 장소 | 이동 묘사 없는 위치 변경 | 이동 사건/생략 가능성 검토 |
| 수치 | 계약 비용 15만→30만 | 계약 변경·통화·범위 확인 |
| 자산 | 송금 후 현금 그대로 | 반대 입금, 차입, 계정 차이 확인 |
| 계약 | 이미 양도 동의된 권리를 다시 승인 | 추가 조건·다른 계약인지 검토 |
| 관계 | 관계 상태가 근거 없이 역전 | 시점별 사건 확인 |

## 권장 판정 체계

- CONFIRMED_CONFLICT: 같은 조건·시점의 근거가 충돌
- NEEDS_REVIEW: 설명되지 않은 차이, 원문 확인 필요
- EXPLAINED_CHANGE: 변경을 뒷받침하는 사건 존재
- INSUFFICIENT_EVIDENCE: 판단할 근거가 충분하지 않음

각 결과에 회차/원문 위치, 비교한 사실, 상태 전이, 판단 이유, 신뢰도를 반환한다. 경고를 자동으로 원고에 반영하지 않는다.
