# 목적과 범위

## 프로젝트 정의

NovelGraph는 소설 원고에서 이야기의 사실·변화·인과관계를 추출해 근거와 함께 저장하고, 회차별 세계 상태 및 서사 연속성을 검증하는 분석 시스템이다.

## 성공 조건

- 인물·조직·장소·시간·사건·자산·계약·관계를 원문 위치와 연결한다.
- 원문에서 명시된 사실, LLM의 해석, 검토 대기 후보를 분리한다.
- 회차 종료 시점의 상태를 재구성하고 원문 근거를 제공한다.
- 정상적 상태 변화와 설정 모순을 구분해 오탐을 줄인다.
- 원고 제공과 처리 결과 회신은 Moon MCP 중심으로 동작한다.
- 자동 집필 기능을 포함하지 않는다.

## 검증 유의

원고 의미 해석의 품질은 CLI 테스트 통과만으로 증명되지 않는다. 장편 전체를 대상으로 정확도, 재현율, 오탐, 누락, 잘못된 상태 전이 등을 별도로 평가해야 한다.
