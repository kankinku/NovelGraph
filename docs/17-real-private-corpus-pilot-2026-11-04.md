# [8/9] 비공개 실제 원고 1~5화 파일럿 실측 — 2026-11-04

> 상태: **원본 보존·후보 수집·검증용 상태 조회·그래프 추적 완료. 독립 금표준 정확도 평가는 미완료.** 이 문서는 비공개 원문의 내용이나 인용을 포함하지 않는다.

## 검증 환경

- 현재 Moon `/shared/NovelGraph`, Python 3.12.3, SQLite, Graphify 0.9.102.
- **기존 56개 테스트** Moon 환경에서 모두 통과. 이후 추가된 파일럿 평가 도구 12개 테스트와 회차 처리 준비 5개 테스트를 포함한 **73개 전체 테스트도 별도 Moon 작업 트리에서 통과** (206.841초).
- 2026-11-04 연결 장애로 인해 보류했던 [6·7/9] Moon 검증은 해소되었다.
- 원고 데이터는 Git 작업 트리 바깥의 접근 제한된 private 영역에만 위치한다. 인용문이 포함된 분석·검토 대장은 **private 디렉터리에만** 보관한다.

## 1. 실제 사용자 제공 파일 검증

- 동일 작품의 1~5화 5개 파일 사용.
- 원본 5개 바이트 SHA-256과 private 보존본의 해시가 모두 일치한다.
- 원문 1~3화는 CRLF→LF만 변환한 **분석용 사본**을 별도로 생성했다. 원본은 재구성해 바이트 단위 해시까지 대조하고 독립 보존했다. 4~5화의 분석본은 원본 바이트와 동일하다.
- `source-info`, `import-candidates`와 원문 문자 범위 검증을 실제 private 파일에 실행했다.

| 회차 | 수집된 원문 근거 후보 | 공식 승인·상태 적용 |
| --- | ---: | --- |
| 1화 | 12 | 0 |
| 2화 | 2 | 0 |
| 3화 | 4 | 0 |
| 4화 | 3 | 0 |
| 5화 | 5 | 0 |
| **합계** | **26** | **0** |

재수입 테스트에서 26건 전부 중복으로 판정되고 신규 후보는 0건이었다. 실제 후보 DB는 **26건 모두 `proposed`**이다.

## 2. 분리된 모델 검토 사본의 연동 시험

실제 후보 DB를 건드리지 않는 **별도 검증 사본**에서 25건을 모델 검토 승인 형식으로 처리하고 1건을 보류했다. 이 승인은 **사용자 또는 독립 인간 검수자의 승인으로 볼 수 없다.**

- 3화 시점 Graphify: **39노드 / 36관계**, 근거 회차 1~3만 포함
- 5화 시점 Graphify: **55노드 / 58관계**, 근거 회차 1~5 포함
- 방향성을 유지한 관계 조회와 회차·문자 위치·원문 SHA를 통한 근거 역추적 성공
- 제한된 승인 형식 연속성 주장 3화 5건, 5화 7건에 대해 경고 0건
- 공식 현금·총자산은 미상으로 유지하고 상태 변경 사건 0건; 동일 과거 지출 언급을 여러 번의 신규 지급으로 간주하지 않음

**주의:** 경고 0건은 전체 소설 무오류/높은 검출 정확도라는 뜻이 아니다. 이번 파일럿은 사람이 선별한 일부 주장만 구조화한 표본이다.

## 3. 평가 도구 및 수치의 정직한 해석

[`pilot-evaluate`](../novelgraph/pilot_eval.py)를 실제 원고 5화 SHA-256 manifest와 연결하는 **스모크 테스트**에 사용했다. 인간 검수 골드가 아직 없어서 `precision`, `recall`, `F1`은 **모두 null**이며 성능 점수를 산출하지 않았다. 비어 있는 임시 gold 데이터는 정답표가 아니다.

| 완료 | 미완료 |
| --- | --- |
| 원고 해시·출처 오프셋 검증 | 사람의 독립적 정답표 |
| 후보 26건 격리 및 재등록 방지 | 미추출 사실의 누락률/FN |
| 승인 분리 시험·그래프 경로 추적 | 실제 오류 검출의 정밀도·재현율 |
| 과거/미래 회차 그래프 분리 | 장편 43화 전수 적용 |

## 4. [9/9] 준비 상태

일반화된 읽기 전용 `batch-readiness` 검사를 실제 private 원고에 실행했다.
- **현재 제공된 5화 기준:** 5/5 원고 해시 확인, 누락 및 DB 미등록 회차 0, 검토 대기 26건.
- **43화 입력을 가정한 범위 테스트:** 미제공 6~43화 38개를 누락으로 올바르게 감지. **이 결과는 지금 받은 5화 작품이 과거 계획의 43화 작품과 동일하다는 뜻이 아니다.**
- PR [#5](https://github.com/kankinku/NovelGraph/pull/5) 병합 완료, 커밋 `dfbe02b`, 전체 73개 테스트 Moon 통과.
