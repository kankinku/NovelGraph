# [12/12] 실제 파일럿 전수 감사 및 출시 판정 — 2026-11-05

> **판정: 정식 출시 NO-GO / 제한적 비공개 검수 파일럿은 운영 가능.** 이 문서는 *출시 게이트의 측정 결과*이다. 12단계 업무의 **평가 수행**과 시스템의 **정식 출시 승인**을 구별한다. 원본 전체의 의미 분석 정확도와 독립 인간 정답표는 아직 검증되지 않았다.

## 1. 검증 범위 및 데이터 경계

- 기준: NovelGraph `main` 커밋 `ba669cdf` (11단계 구현).
- 동일 작품 `ashcroft_pilot`의 **현재 접근 가능한 1~5화**만 대상으로 공식 원장·원본 SHA·후보를 읽기 전용 감사했다. 실제 원고·DB·보고서 원문은 GitHub 저장소 외부의 비공개 데이터 영역에 둔다.
- 공식 SQLite 원장 외에 11단계에서 만든 **비공개 백업본과 새 파일 복원본**을 대조했다. 세 파일을 상호 교체하거나 수정하지 않았다.
- 1~3화 공식 *분석본*은 보존된 원본의 CRLF→LF 줄바꿈 정규화와 일치한다. 4~5화 공식 분석본은 원본과 바이트가 동일하다. 판본 이력을 지우거나 다른 작품의 원고로 대체하지 않았다.
- 과거 **43화 전체 목표**와 현재 1~5화가 같은 작품이라는 근거가 없다. 따라서 `batch-readiness --target 43`의 6~43화 미제공 38건은 **현재 작품을 가정한 시험 수치**이지, 별도 43화 작품의 실제 결손으로 보고하지 않는다.
- `source-manifest.json`은 초기 보존 목록(list)이라 `batch-readiness` 입력 계약에 맞지 않는다. 실제 검증에서는 작품 ID·회차·SHA가 있는 **`evaluator-manifest.json`**을 사용했다. 형식 오류를 고치려고 원본 manifest를 덮어쓰지 않았다.

## 2. 원본·원장·근거 무결성 실측

| 검증 항목 | 실제 결과 | 의미와 한계 |
| --- | --- | --- |

| 중복 원고 SHA | **0건** | 5개의 서로 다른 바이트 SHA |
| 회차 누락(1~5화 범위) | **0건** | 현재 대상 구간만 완전 |
| 등록된 공식 후보 | **26건** | 1~5화에 12/2/4/3/5건 |
| 공식 후보의 불변 ID·SHA·Unicode 원문 위치 | **26/26 일치** | 구조·출처 검증. 의미상 정확도 검증이 아님 |
| 추가된 모델 예비 검토를 포함한 작업표 | **71/71 원문 근거 유효** | 독립 사람 검토 완료 **0건** |

## 4. 독립 검수 없이는 계산하지 않는 수치

이번 상태에서 오탐(FP)·누락(FN), TP, precision/recall/F1을 **0/0 또는 100%로 기록하면 오류**다. 이유:

1. 사람이 원고 전체를 블라인드 판독해 만든 진짜 사실·오류 목록이 존재하지 않는다.
2. `gold-not-reviewed.json`의 빈 `findings` 배열은 부정 사례 0건으로 확정된 정답표가 아니다.
3. `pilot-evaluate`는 *이미 검증된 오류 정답표*와 검출 결과를 비교하는 도구이며, 모든 사실 추출의 완전성 평가를 대신하지 않는다.
4. 현 공식 승인 사실 0건이어서 실사용 연속성 검출의 참양성/거짓양성을 판정할 수 없다.

따라서 **정밀도=null, 재현율=null, F1=null**, 실제 FP/FN **미측정**으로 유지한다. '95%'는 목표 수치이며 달성 실적이 아니다.

## 5. 출시 등급·판정 기준

**현재 허용: 내부 개발 및 제한적 비공개 파일럿.** 사람이 검토하기 전 `proposed` 상태로 후보를 모으고 SHA·근거·상태·백업을 관찰하는 용도다. 생성 후보를 작가에게 '확정 오류'로 자동 전달하거나 공식 설정·금액으로 자동 승격하는 정식 서비스는 허용하지 않는다.

**정식 출시: NO-GO.** 다음 다섯 항목 중 하나라도 미충족이면 유지한다.

1. **Gold:** ChatGPT의 모델 판단과 독립된 사람 검수자가 동일 작품 원문 전체를 먼저 블라인드로 읽고 1차 사실·오류 정답표를 작성. 그 뒤 71건 후보와 2차 대조·검수 판정을 완료해 승인 근거를 남길 것.
2. **Meaning:** 실제 오탐·누락·모순 유형(날짜/요일, 위치/행동, 비용·자산, 계약 동의 등)을 사람 기준으로 분류하고 개선 전후 성능을 **실측**할 것.
3. **Approval:** 승인자가 실제 사용자/권한자라는 인증 경계와 누가 어떤 근거로 상태를 승인했는지 검증 가능한 승인 절차를 확정할 것.
4. **Coverage:** 실제 적용할 **동일 작품**의 전체 대상 회차·판본·SHA manifest를 확보하고, 1~5화 → 중간 → 마지막 구간 순서로 처리 후 누락과 수정 판본 충돌이 없음을 확인할 것.
5. **Release trial:** 정답·로그를 기준으로 중복 지급 0, 근거 오프셋 오류 0, 승인 전 상태 적용 0, 강제 중단 후 복구 성공 및 필요한 오류 탐지 정확도 목표를 검증할 것.

**지금 당장 기술적으로 할 수 있는 다음 일**은 비공개 1~5화의 *블라인드 전체 원고 검수→71건 대조→사람의 실제 승인*을 요청·완료하는 것이다. 그 전에는 동일한 모델의 반복 판단으로 정답을 대신하지 않는다.

## 6. 재현 도구, 보존 경로, 공개 제외

기존 CLI만으로 작업이 가능해 신규 실서비스 API·MCP·LLM SDK를 추가하지 않았다.

```bash
cd /shared/NovelGraph
ROOT=/shared/NovelGraph-data/works/<private-work>
.venv/bin/python -m novelgraph --data-root "$ROOT" batch-readiness \
  --manifest "$ROOT/reports/evaluator-manifest.json" --target 5
.venv/bin/python -m novelgraph --data-root "$ROOT" review-readiness \
  --worksheet "$ROOT/reports/fact-review-worksheet-v2-20261105.json"
.venv/bin/python -m novelgraph --data-root "$ROOT" workflow-status \
  --work-id ashcroft_pilot --episode 5 --source "$ROOT/source/005.txt"
.venv/bin/python -m novelgraph --data-root "$ROOT" review-audit \
  --work-id ashcroft_pilot --episode 5
.venv/bin/python -m novelgraph --data-root "$ROOT" source-version-audit \
  --work-id ashcroft_pilot --episode 5 --source "$ROOT/source/005.txt"
```

위 예시는 **기존 파일럿 대상 전용**이며 다른 작품에 그대로 복사할 때는 작품 ID·manifest·파일명·원고를 반드시 변경한다. 실제 비공개 감사에서는 다섯 회차의 원본/분석본·후보 불변 ID·DB 3개를 교차 검증했다. 테스트 스크립트와 스냅샷 결과는 비공개 개인 작업공간에만 남긴다. 실제 본문 인용, 원고 파일명, 후보 payload, 정답 작업표는 **공개 Git에 넣지 않는다**.
