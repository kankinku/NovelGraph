# [9/9] 1~43화 실전 적용 준비

NovelGraph [9/9] 목표는 동일 작품 1~43화의 순차 분석, 인물·사건·계약·자산 상태 추적, 근거 기반 연속성 검사, Graphify 관계 조회 및 재현 가능한 오류 보고다.

## 시작 조건
- 같은 작품의 최신 원고를 001.txt~043.txt로 제공받는다. ZIP 가능.
- 소설 원고·후보·분석 DB는 /shared/NovelGraph-data 등 비공개 위치에서만 관리한다. 공개 GitHub에 올리지 않는다.
- 각 회차 원본의 SHA-256·문자 길이·판본·회차 순서를 고정한다.
- 먼저 1~3화를 분석하고 독립 검토 정답표로 오탐·누락·근거 정확도를 평가한다. 기준을 통과하지 못하면 43화 전체로 확대하지 않는다.

## 전체 적용 프로토콜
1. 1~43화 파일 개수·중복·누락·인코딩·원본 해시 사전 검사
2. 회차 순서대로 ChatGPT가 의미 후보 추출 → Moon MCP로 후보 JSON 전달
3. 원문 구절과 Unicode 위치 검증 → proposed 상태 격리
4. 검토한 후보만 승인 → 상태 사건 적용 (계약 서명·지급·권리 이전 분리)
5. 각 회차 후 현금·투자·지분·관계 등 세계 상태 조회 및 연속성 검사
6. 승인된 데이터만 Graphify 파생 그래프로 반영
7. 오류 목록: 작품·회차·원문 위치·비교 근거·오류 구분·추가 확인 필요 여부
8. 결과 평가: 정밀도·재현율·F1, 오탐·누락, 실패/미승인 건수, 재현 절차

## 완료 판정
- 누락된 회차 없이 1~43화 처리 기록 존재
- 승인 전 후보는 공식 상태에 미반영
- 원고 수정/판본 변경은 해시로 감지
- 실측된 검출 성능·오탐·누락을 보고 (미측정이면 미측정으로 명시)
- 공개 저장소에는 코드·문서·가상 테스트만 보관
- 기존 NovelGraph 과거 원본 복구는 미해결 별도 과제로 추적

## 현재 상태
[8/9] 평가기 CLI는 GitHub main에 반영되었으나 실제 원고 1~3화 평가 미실시. [9/9] 전체 원고 입력과 순차 분석 역시 미실시. Moon 연결은 불안정하므로 정상 재접속 후 갱신·테스트가 필요하다.
