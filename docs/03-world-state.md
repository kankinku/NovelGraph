# 동적 세계 상태 모델

## 기본 개체

- Entity: 인물, 회사, 장소, 물건, 금융자산, 계약
- Event: 계약 서명, 지급, 권리 이전, 투자, 매각, 이동, 관계 변화
- StateAssertion: 특정 시점에 성립하는 상태
- Evidence: 회차, 청크, 원문 위치, 원문 인용
- Review: 확인/추정/보류/반박 등 판정과 근거

## 중요 구분

- 투자 검토 ≠ 투자 승인 ≠ 약정 ≠ 송금 ≠ 지분 취득
- 계약 체결 ≠ 이행 완료 ≠ 권리 행사
- 현금 ≠ 순자산 ≠ 총자산 ≠ 미실현 평가액
- 보유 주식 ≠ 취득 예정 주식
- 확정 사실 ≠ 추론 후보

## 예시 (가상)

1. 1화: 투자 검토 → 금액 변동 없음
2. 2화: 투자 한도 2만 5,000달러 설정 → 잔액 변동 없음
3. 3화: 지분 15% 계약 서명 → 지급 조건 확인 전 잔액/지분 취득 확정 금지
4. 후속 화: 실제 송금 및 권리 이전 확인 → 각 시점의 현금 및 지분 상태 갱신

## 상태 전이 기본 요구

- 사건 발생 시점과 서술 시점을 별도로 기록한다.
- 수정·취소·계약 무효 사건은 기존 사실을 무조건 삭제하지 않고 이력으로 연결한다.
- 금액은 통화, 단위, 평가 시점, 계정 범위를 포함해 다룬다.
- 시점별 질의에서 미래 사건이 과거 상태를 오염시키지 않게 한다.
- 같은 원고와 같은 사건을 중복 처리하지 않는다.
