# [02/12] 독립 검수 준비도 검사 — 2026-11-05

> **판정:** 원문·검수 메타데이터의 기계 검증 도구 구현. **사람의 독립 검수 자체는 미완료.** 이 도구는 검수자 신원을 인증하거나 정답표를 공식 승인하지 않는다.

## 작업 목적

실제 원고 1~5화의 기존 후보 26건과 모델 예비 제안 45건은, 원문 근거가 일치한다고 해서 바로 인간 검수 금표준이 되는 것이 아니다. 검수 상태를 임의로 `complete_gold: true`로 바꾼 입력이 작업 완료처럼 보이는 것을 피하고, **사람이 검토할 자료가 준비되어 있는지** 판정하는 읽기 전용 검사를 추가했다.

## 명령

```bash
cd /shared/NovelGraph
.venv/bin/python -m novelgraph \
  --data-root /shared/NovelGraph-data/works/ashcroft-pilot-20261104 \
  review-readiness \
  --worksheet /shared/NovelGraph-data/works/ashcroft-pilot-20261104/reports/fact-review-worksheet-v2-20261105.json
```

이 명령은 분석 원문을 출력하지 않는다. 파일 읽기만 수행하고 SQLite나 후보 JSON에 쓰지 않는다.

## 실제 비공개 원고 검증 실측

| 항목 | 결과 |
| --- | ---: |
| 원본 판본 SHA 일치 | 5/5화 |
| 후보의 원문 위치·근거 일치 | 71/71건 |
| 인간 검토 완료 후보 | 0/71건 |
| 본문 전체 독립 검토 완료 회차 | 0/5화 |
| 검수 완료로 승격 가능 여부 | **false** |
| 인증된 검수자 여부 | **false** (별도 인증 기능 없음) |
| 공식 확정 정답표 여부 | **false** |

**주의:** 71건이 실제 작품의 중요 사실 100%를 포괄한다는 의미가 아니다. 기존 후보와 모델이 선정한 예비 추가 항목의 수를 합산한 검토 대기 목록일 뿐이다.

## 검증 범위

- 비공개 작업표가 입력 조건에 부합하는지 확인
- 원본 파일이 지정한 비공개 루트 바깥으로 나가지 않는지 검사
- 회차별 파일의 실제 SHA-256과 작업표 SHA 일치
- 모든 후보·독립 판독 사실의 Unicode 문자 범위·원문 인용 일치
- 후보 검토 ID·독립 판독 사실 ID 중복 검사
- 1차 전체 본문 검토, 10가지 범주별 확인, 2차 후보별 검토 메타데이터의 완결성 판단
- 검토자 이름이나 외부 서명을 실제 인증된 증거라고 주장하지 않음
- 모든 메타데이터가 채워져도 `ready_for_manual_signoff=true`까지만 허용하며 `gold_standard_verified=false`를 유지

실제 사용 전에는 독립 검토자의 판정과 확정 승인이 별도로 필요하다. 특히 이름과 날짜 문자열은 인증 수단이 될 수 없다.

## TDD 및 근거

- 신규 기능을 구현하기 전 합성 데이터 기반 10개 실패 테스트를 작성했다. 당시 `review-readiness` 명령이 없어서 모두 예상대로 실패했다.
- 기존 CLI에서 세부 도메인 상태를 바꾸지 않도록 작은 모듈 `novelgraph/review_readiness.py`만 추가했다.
- 신규 10개 테스트 통과. 전체 회귀 테스트 결과는 최종 PR에 기록한다.
- 테스트에는 원본 소설 문장을 포함하지 않는다.
- 비공개 모델 자체 재검토 결과, 기존 26건 중 **5건**에 상태·증거 해석상 확인 필요 사항을 분리 기록했다. 모두 **모델의 검토 의견**이며 확정 오류 또는 인간 판단 결과가 아니다.

## 추후 보강 시점
