# [02/12] 독립 검수용 블라인드/대조 자료 분리 — 2026-11-05

> **판정: 검수 자료 준비 기능 구현·비공개 1~5화 적용. 독립 인간 검수 및 정답표 확정은 미완료.**

## 문제와 개선

이전 `fact-review-worksheet-v2-20261105.md`는 1차 독립 원고 검토 지침과 모델 후보 71건을 한 문서에 담았다. 검수자가 모델 후보를 먼저 보면 모델이 놓친 중요 사실을 독립적으로 발견하기 어려울 수 있다.

개선으로 기존 원고·후보·DB는 변경하지 않고 **서로 다른 비공개 Markdown 자료 두 개**를 생성하는 작은 CLI를 추가했다.

1. **1차 독립 판독표:** 회차, 검토 범주, 독립 사실 기록 안내만 수록. 모델의 71개 주장·인용·후보 ID를 넣지 않는다. 검수자는 별도의 원본 원고를 읽고 직접 사실 목록을 작성한다.
2. **2차 후보 대조표:** 1차 판독 이후에만 열어보는 모델 후보 71건, 인용 및 원문 오프셋. 검수자는 정확/부분정확/중복/근거부족/부정확을 독립적으로 기록한다.

별도 비공개 참고자료에서는 **기존 후보 5건**의 상태·거래 해석과 **추가 제안 후보 4건**의 근거 범위 문제를 합쳐 총 **9건**을 우선 검토하도록 정리했다. 이 9건은 확정 오류가 아닌 **모델이 제안한 추가 확인 사항**이며, 비공개 `priority-review-questions-v2-20261105.md`에 기록돼 있다.

## 사용법

```bash
ROOT=/shared/NovelGraph-data/works/ashcroft-pilot-20261104
cd /shared/NovelGraph
.venv/bin/python -m novelgraph --data-root "$ROOT" prepare-review-packets \
  --worksheet "$ROOT/reports/fact-review-worksheet-v2-20261105.json" \
  --blind-output "$ROOT/reports/independent-first-pass-20261105.md" \
  --comparison-output "$ROOT/reports/model-candidate-second-pass-20261105.md"
```

이미 만들어진 파일을 덮어쓰지 않는다. 새 파일명이 필요하면 별도 이름을 지정한다. 출력 부모 디렉터리는 private 루트 아래여야 하고 그룹/기타 접근이 차단되어 있어야 한다. 파일 권한은 `0600`이다.

## 비공개 실측

| 검증 사항 | 확인 결과 |
| --- | --- |
| 원고 | 5화 |
| 1차 판독표 | 원고의 모델 후보·본문 인용 미포함 |
| 2차 후보 대조표 | 기존 26건 + 모델 추가 제안 45건 = 71개 |
| 근거 SHA·인용 검증 | 71/71 통과 |
| 모델이 우선 확인을 권고한 항목 | 9건 (기존 후보 5, 추가 제안 4; 비공개) |
| 사용자·독립 인간 검수 완료 | 0건 |
| 금표준 정답표 | 미확정 |
| 공식 DB 승인·적용 | 0건 추가 |

**중요:** 블라인드 문서를 따로 만들었다는 사실만으로 인간 검수의 독립성이 증명되는 것은 아니다. 사람이 실제로 원고 전체를 읽었는지, 모델의 이전 판단에 노출되지 않았는지는 별도로 확인해야 한다.

## TDD와 데이터 안전

- 합성 원고를 사용한 실패 테스트를 기능 구현 이전에 실행, 없는 CLI가 실패하는 RED를 확인했다.
- 새 파일을 덮어쓰려는 경우, 비공개 루트 외부 경로, 원문 근거가 변조된 경우, 두 출력 경로가 같은 경우를 차단.
- 추가로 잘못된 유니코드 문자 입력 시 생성 도중 파일이 남는 문제를 테스트로 재현해, 작성된 임시 산출물을 제거하도록 보완.
- 분리 산출물은 공개 GitHub에 포함하지 않으며, 파일 생성 명령은 SQLite 후보·승인·세계 상태를 변경하지 않는다.
- 최종 수정 후 **전체 90개 테스트가 Moon 격리 작업 트리에서 통과**했다 (`python -m unittest discover -s tests -v`, 221.585초).
