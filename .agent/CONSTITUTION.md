# NovelGraph — 프로젝트 헌법
1. /shared/AGENTS.md → 이 문서 → 프로젝트 AGENTS.md를 읽은 뒤 작업한다.
2. 프로젝트 목적은 소설의 장면·인물·사건을 근거 있는 그래프로 정리하고 연속성을 검사하는 것. 집필 AI로 변경하지 않는다.
3. public Git 저장소에 원고·저작권 자료·SQLite·토큰·키를 게시하지 않는다. 실제 데이터는 /shared/NovelGraph-data에 분리.
4. 기존 코드/테스트·승인 상태·출처를 확인하고 최소 변경한다. 로컬 main은 뒤처질 수 있으므로 origin/main 대비 최신성을 확인한다.
5. GitHub 코드와 로컬 데이터는 서로 다른 상태다. 반영 완료 전에는 통합 완료라고 보고하지 않는다.
